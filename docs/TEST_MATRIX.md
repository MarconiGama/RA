# Matriz mínima de testes em aparelhos

| Categoria | Cenário | Resultado esperado |
|---|---|---|
| Instalação | APK novo | Instala sem erro |
| Permissão | Câmera permitida | Rastreamento inicia |
| Permissão | Câmera negada | Mensagem clara e app estável |
| Inicialização | Abrir app | Menu aparece sem travar |
| Navegação | Menu para SampleScene | Cena RA carrega |
| Rastreamento | Targets A–Z | Conteúdo correto para cada target |
| Iluminação | Ambiente claro e moderado | Reconhecimento consistente |
| Offline | Sem internet | Conteúdo principal funciona |
| Progresso | Reiniciar app | Conclusões permanecem |
| Reset | Limpar perfil | Progresso é removido |
| Desempenho | Sessão de 15 minutos | Sem aquecimento ou queda crítica |
| Interrupção | Minimizar e retornar | Câmera e cena recuperam |

Registrar por aparelho: fabricante, modelo, Android, RAM, tempo de inicialização, tempo médio de detecção e falhas observadas.
