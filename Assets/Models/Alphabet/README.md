# Modelos do alfabeto para Unity

FBX/ contém os modelos de intercâmbio, Materials/ os materiais Standard simples e Prefabs/ os prefabs normalizados. Todos os artefatos A–Z e seus .meta são versionados.

Não edite FBX, materiais gerados ou prefabs manualmente. Altere o gerador Blender, regenere, valide e execute AlphabetModelImporter. Cada prefab deve manter nome RA_Letter_X, posição/rotação zero, escala um, uma mesh, um material e nenhum script, câmera ou luz.

A cena legado não é atualizada automaticamente. Consulte docs/art-pipeline/UNITY_MODEL_MIGRATION_PLAN.md antes de substituir um objeto Vuforia.
